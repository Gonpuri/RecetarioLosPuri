# SGRF-EIS-001
Capítulo 6 – UX/UI (Experiencia e Interfaz de Usuario)

**Versión: **1.0
**Objetivo: **Definir los criterios de experiencia de usuario e interfaz para garantizar una aplicación simple, consistente y orientada al uso cotidiano en la cocina.

## 6.1 Objetivos de UX

El sistema deberá minimizar la cantidad de pasos necesarios para consultar una receta, escalarla y generar una lista de compras. La interfaz deberá priorizar la lectura durante la preparación por encima de las funciones administrativas.

## 6.2 Perfil de Usuario

El público objetivo está compuesto por integrantes de una familia con distintos niveles de experiencia tecnológica. La interfaz deberá ser intuitiva, con navegación simple y lenguaje claro.

## 6.3 Principios de Diseño

• Simplicidad.
• Consistencia visual.
• Legibilidad.
• Accesibilidad.
• Rapidez de acceso.
• Prioridad al contenido.

## 6.4 Identidad Visual

Color principal: Azul Francia.
Color secundario: Blanco.
Estados:
- Éxito: Verde.
- Advertencia: Amarillo.
- Error: Rojo.
Tipografía: Sans Serif, tamaño base 16 px.

## 6.5 Navegación

Menú principal:
- Inicio.
- Recetas.
- Categorías.
- Favoritos.
- Lista de Compras.
- Configuración.

La búsqueda deberá estar disponible desde la pantalla principal.

## 6.6 Pantallas Principales

• Inicio.
• Listado de recetas.
• Detalle de receta.
• Edición de receta.
• Gestión de preparaciones.
• Lista de compras.
• Configuración.

## 6.7 Componentes

Botón primario: Guardar, Crear, Escalar.
Botón secundario: Cancelar, Volver.
Tarjeta de receta con fotografía, nombre, rendimiento y categorías.
Chips para etiquetas.
Modal para confirmaciones.

## 6.8 Flujo de Usuario

1. Buscar receta.
2. Abrir receta.
3. Seleccionar rendimiento.
4. Escalar cantidades.
5. Marcar ingredientes faltantes.
6. Generar lista de compras.
7. Cocinar.

## 6.9 Accesibilidad

La interfaz deberá:
- Funcionar en dispositivos móviles y escritorio.
- Mantener buen contraste.
- Soportar modo oscuro (futuro).
- Permitir ampliación del tamaño del texto.

## 6.10 Responsive Design

Las pantallas deberán adaptarse a teléfonos, tablets y computadoras sin perder funcionalidad. En móviles se priorizará el desplazamiento vertical y botones de fácil acceso.

## 6.12 Criterios de Calidad

• No más de tres toques para abrir una receta.
• La acción de Escalar debe ser visible.
• Los ingredientes deben tener mayor protagonismo visual que los datos administrativos.
• Los mensajes de error deben ser claros y accionables.

## 6.13 Conclusión

La UX/UI del SGRF debe acompañar el proceso natural de cocinar. Cada decisión de diseño debe reducir la complejidad, facilitar la lectura y mantener el foco en la receta y su preparación.
